# Minibus Stop Simulation (C++)

## Project Description

This project simulates the operation of a minibus stop. It models passenger arrivals, minibus arrivals, passenger queues, and the boarding process over a specified simulation period.

The simulation tracks the time passengers arrive at the stop, the time they board a minibus, and the time minibuses arrive.

## Main Features

- Passenger arrival simulation.
- Minibus arrival simulation.
- FIFO queue for waiting passengers.
- Random number of free seats in each minibus.
- Passenger boarding based on available seats.
- Support for terminal and regular stops.
- Tracking passenger and minibus arrival times.
- Calculation of the average passenger waiting time.
- Displaying simulation statistics.

## Technologies

- C++
- Object-Oriented Programming (OOP)
- Templates
- Dynamic Arrays
- Dynamic Memory Management
- FIFO Queue
- Classes and Encapsulation

## Purpose

The purpose of this project is to practice object-oriented programming, template classes, dynamic memory management, and queue data structures while developing a simple event-based simulation.
